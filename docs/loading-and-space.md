前版 GLB 為 7,832,032 bytes，其中圖片占 89.5%。2026-09-15 實測 GitHub Pages gzip 傳輸 7,097,152 bytes、65.3 秒，首個位元組 0.29 秒；這是當次網路量測，不能視為平台固定速度。

先比較代表作品在 1024 像素的 JPEG 與 WebP，保留細線、文字與色塊；場景採清晰 WebP，詳情保留 2048 像素。預覽只負責首次顯示，清晰圖依目前視野優先載入，並限制並行請求。SVG 旗幟直接作為網頁貼圖來源。
