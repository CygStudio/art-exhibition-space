# 載入效能與展間深度校正

日期：2026-09-21。依使用者補充、IMG_9426、IMG_9407 與 DJ 影片 0–2、30–34 秒調整。

## 本次判讀

- 平面圖上下為 Z 軸，擴大的是空間深度。兩根柱子保持 X=−1.25、Z=−2.94／3.0，間距 5.94 公尺；兩端牆由 Z=±5.1 外移至 ±6.3。尺寸是工作模型的推估，並非現場量測。
- 服務台區的縱深與工作側空間一併加大。照片顯示米色落地桌布、兩件較大的桌上展示框、右側黑色玻璃機殼與彩色風扇；取代原本三張等大的粉紅卡片及單一實心設備方塊。
- 簽到桌旗幟以紅底、黑色行星／星芒圖案製作平面 SVG，不帶照片的皺褶、陰影或反光。圖案依可見參考簡化，不宣稱是官方向量原稿。
- 原始作品與完整 Blender 編輯檔保留。網站資產分為小型預覽、場景貼圖與詳情大圖，避免以全部清晰作品的下載完成作為進場條件。

## 效能基準與取捨

前版 GLB 為 7,832,032 bytes，其中圖片占 89.5%。2026-09-15 實測 GitHub Pages gzip 傳輸 7,097,152 bytes、65.3 秒，首個位元組 0.29 秒；這是當次網路量測，不能視為平台固定速度。

先比較代表作品在 1024 像素的 JPEG 與 WebP，保留細線、文字與色塊；場景採清晰 WebP，詳情保留 2048 像素。預覽只負責首次顯示，清晰圖依目前視野優先載入，並限制並行請求。SVG 旗幟直接作為網頁貼圖來源。

## 提交階段

1. 記錄影像判讀與調整範圍。
2. 分級圖片、平面 SVG 旗幟與漸進載入。
3. 展間深度、服務台及同步的導覽／碰撞／小地圖。
4. 建置、資產與導覽測試、桌面／手機畫面及慢速／失敗情境驗證。

## 完成結果

- 初始 GLB：1,046,476 bytes（比前版減少 86.6%）；本機 gzip：267,496 bytes（前版實測 gzip 約 7.10 MB）。圖片預覽與三張桌上展示圖合計 120,759 bytes。
- 場景清晰貼圖：27 張 WebP（含服務台背板）、1 張 JPEG（lllokkk 直幅）、1 張 SVG 旗幟；場景點陣圖共 3,248,049 bytes，但不在進場前全部下載。
- WebP 一般品質 88，細節較多的 kakult 兩幅與 lllokkk 橫幅採 90。以三件代表作品檢查 1024 px 的 JPEG 90、WebP 86／90 局部畫面；lllokkk 直幅的飽和紅色細線在 WebP 有色彩流失，保留 JPEG 4:4:4。PSNR 僅作輔助，不當成畫質保證。2048 px 詳情圖維持原有品質 92。
- GLB 預覽最長邊 128 px；目錄縮圖 320 px；場景清晰圖 1024 px。SVG 升級後直接使用向量來源，Blender 保留其 PNG 衍生材質。
- 空間由 10.8 × 10.2 調整為 10.8 × 12.6 公尺；柱子中心距不變。柱子外緣到兩端牆面中心線的間距分別由 1.91／1.85 增至 3.11／3.05 公尺。尺寸為推估，不沿用先前「約 30 坪」的面積結論。
- 服務桌由 3.25 × 0.82 改為 3.4 × 1.08 公尺。桌面補上照片中的展示框與黑色機殼，桌布改為連續曲面皺褶；機殼保留簡化外形與彩色風扇，不重建品牌、螢幕文字或不可辨識的內容。
- 完整畫作保留於 `.blend`；網站 GLB 單獨開啟只有預覽品質。四角校正後的服務台背板與 SVG 旗幟皆使用完整 UV。

## 驗證

- `pnpm test`：31 項通過，包含限流、視野排序、失敗重試、UV、資產預算、柱距、加深邊界、小地圖完整顯示及所有導覽／作品定位可達。
- `pnpm build`：通過。Three.js 所在 JS 仍有原有的 500 kB chunk 提醒；本機 gzip 約 158 kB，未宣稱 JavaScript 已拆包。
- 正式版 `dist/` 透過本機測試伺服器提供 gzip、全連線共用 105,000 bytes/s、每回應延遲 100 ms、`Cache-Control: no-store`：`gallery-interactive` 在 5,206.7 ms；GLB 請求耗時 2,927.6 ms。清晰圖在 5,300.9 ms 後開始請求，初始未請求詳情大圖。這是單次模擬量測，並非正式網站速度承諾。
- 瀏覽器阻擋 `artworks/scene/*`：展間仍可操作及切換主展牆，28 張點陣作品保留預覽，另 1 張 SVG 旗幟正常載入。
- 桌面 1440 × 1000：檢查服務台、旗幟、主展牆與擴大後的柱牆空間；正常流程無未處理 JavaScript 錯誤。
- 手機 390 × 844：頁寬仍為 390，目錄使用獨立縮圖，點擊作品載入詳情圖並正常顯示。
