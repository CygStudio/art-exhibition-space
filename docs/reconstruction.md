## 分階段交付

1. 參考分析與實作規劃（本文件）。
2. Blender 建模：保留 `.blend`、可重現 Python 腳本，匯出網頁用 GLB。共用材質、合併靜態網格、控制細節與材質尺寸。
3. Three.js 網頁：第一人稱拖曳環視、鍵盤與觸控移動、分區導覽、作品選取、原生 DOM dialog 燈箱與作品目錄。
4. 實際瀏覽器驗證、建置檢查、使用文件與修正。

每個階段獨立 commit。

## 座標與資料約定

建模輔助函式使用 Three.js 的 X 右、Y 上、Z 前座標，再轉換為 Blender 座標。展間邊界 X = ±5、Z = ±6。GLB 的作品物件以 `Artwork_01` 命名並帶 `artworkId` 自訂屬性。作品目錄、位置及模型碰撞範圍由同一份建模資料匯出，避免前端與模型不同步。

作品圖像採本地 SVG 抽象示意圖，GLB 載入後由前端套用；換圖只需修改作品資料與圖檔。正式建置不包含 `refs/` 或 Blender 原始檔。
