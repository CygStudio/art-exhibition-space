## 座標與資料約定

建模輔助函式使用 Three.js 的 X 右、Y 上、Z 前座標，再轉換為 Blender 座標。展間外框 X = ±5.4、Z = ±5.1；平面圖上方是 −Z，右方是 +X，不代表已確認地理方位。右上房間占 X = 2.05～5.4、Z = −5.1～−1.65，碰撞範圍包含隔間厚度。GLB 的作品物件以 `Artwork_01` 命名並帶 `artworkId` 自訂屬性。作品目錄、位置及模型碰撞範圍由同一份建模資料匯出，避免前端與模型不同步。`layout` 同時匯出兩張桌子、未使用房間、窗戶、柱子與推估入口視角，前端依此產生小地圖；`viewPosition` 可指定桌前或柱旁作品的安全站位。

作品圖像採本地 SVG 抽象示意圖，GLB 載入後由前端套用；換圖只需修改作品資料與圖檔。正式建置不包含 `refs/` 或 Blender 原始檔。
